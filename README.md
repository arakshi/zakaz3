# ТОиР прототип: «Заявка – заказ – поставка»

1. Откройте проект в PyCharm и создайте интерпретатор **Python 3.11+** (venv).
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте Run Configuration типа **Python** для файла `run_app.py`.
4. Нажмите **Run** — `run_app.py` сам запускает Streamlit программно.
5. Откройте URL из консоли (обычно `http://localhost:8501`).

## Что внутри
- Автосоздание SQLite БД в `data/app.db` при первом запуске.
- Автогенерация 200–400 демо-заявок с заказами, поставками, движениями склада и событиями.
- Роли в UI: Заявитель ТОиР, Планировщик ТОиР, Снабжение, Склад, Руководитель, Админ.
- Low-code экран «Конструктор процесса»: статусы, переходы, приоритизация, SLA, маршруты согласования.
- KPI dashboard + сравнение сценариев **AS-IS vs TO-BE**.
- Реестр заявок: фильтры, быстрые действия, экспорт CSV и printable HTML карточка заявки.
